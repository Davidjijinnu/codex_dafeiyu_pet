# 动画表格式

v2：透明 PNG，1536 × 2288 像素，8 列 × 11 行，每格 192 × 208 像素。每行动作从最左一格起依次排列，其余格完全透明。

| 行号（从 0 开始） | 状态 | 有效帧数 |
| --- | --- | --- |
| 0 | idle / 待机 | 6 |
| 1 | running-right / 向右移动 | 8 |
| 2 | running-left / 向左移动 | 8 |
| 3 | waving / 招手 | 4 |
| 4 | jumping / 跳跃 | 5 |
| 5 | failed / 失落 | 8 |
| 6 | waiting / 等待输入 | 6 |
| 7 | running / 思考工作 | 6 |
| 8 | review / 检查 | 6 |
| 9 | 观察方向前半周 | 8 |
| 10 | 观察方向后半周 | 8 |

观察方向从正上方开始，按顺时针每 22.5° 一帧：

```text
row 9:  000, 022.5, 045, 067.5, 090, 112.5, 135, 157.5
row 10: 180, 202.5, 225, 247.5, 270, 292.5, 315, 337.5
```

`000` 向上、`090` 向屏幕右、`180` 向下、`270` 向屏幕左；静止正面由待机帧提供。

本版本采用统一人物比例与地面基线，为跳跃预留顶部空间。不要分别把每帧人物裁到最大后单独填满画格，否则动作切换时容易出现大小跳变。
